# 🌌 Caelestia Hyprland Shortcuts & Cheat Sheet

A comprehensive quick-reference card for keybindings, gestures, special workspaces, and shell controls.

---

## 🚀 Quick Overview / Top Bar & Drawers

| Shortcut / Trigger | Action | Description |
| :--- | :--- | :--- |
| **`Super`** *(tap)* | **Application Launcher** | Fuzzy search menu and command palette (`Type ">" for commands`). |
| **`Super + K`** | **Top Dashboard** | Media player, performance stats, quick settings, and weather. |
| **`Super + N`** | **Notification Sidebar** | Notification center, DND toggle, Caffeine switch, and screen recorder controls. |
| **`Ctrl + Alt + Delete`** | **Session / Power Menu** | Lock, Suspend, Reboot, Shutdown, and Logout options. |
| **`Super + Shift + W`** | **Nexus Settings** | Wallpaper selector, Material You color palette generator, and UI customization. |
| **`Super + L`** | **Lock Screen** | Instant secure lock screen with PAM authentication. |
| **`Super + Alt + L`** | **Restore Lock** | Restore/wake lock screen state. |

## 🛠️ Utilities & Productive Tools

| Shortcut | Feature | Action |
| :--- | :--- | :--- |
| **`Super + V`** | **Clipboard History** | Fuzzy search clipboard history (`cliphist` + `fuzzel`). |
| **`Super + Alt + V`** | **Delete Clipboard Item** | Remove an item from clipboard history. |
| **`Ctrl + Shift + Alt + V`** | **Paste Latest Item** | Direct type/paste of the newest clipboard entry via `ydotool`. |
| **`Super + .`** | **Emoji Picker** | Search and copy emojis to clipboard. |
| **`Super + Shift + C`** | **Color Picker** | Hex color picker via `hyprpicker` (auto-copies hex code). |
| **`Print`** | **Fullscreen Screenshot** | Saves to `~/Pictures/Screenshots/` and copies to clipboard. |
| **`Super + Shift + S`** | **Freeze Area Screenshot** | Freeze screen and drag a selection to annotate with Swappy. |
| **`Ctrl + Alt + R`** | **Screen Recording** | Start / stop 60 FPS recording with notification controls. |
| **`Super + Alt + R`** | **Screen Recording (Audio)** | Record screen including desktop & microphone audio. |
| **`Super + ALT + W`** | **Random Wallpaper** | Instantly pick and apply a random wallpaper + new theme palette. |

## 🪟 Window Management

| Shortcut | Action |
| :--- | :--- |
| **`Super + Q`** | Close focused window |
| **`Super + F`** | Toggle Fullscreen |
| **`Super + Alt + F`** | Toggle Maximized (bordered fullscreen) |
| **`Super + Alt + Space`** | Toggle Window Floating / Tiling |
| **`Super + P`** | Pin floating window across all workspaces |
| **`Super + Arrow Keys`** | Move focus (Left / Right / Up / Down) |
| **`Super + Shift + Arrow Keys`** | Move window position (Left / Right / Up / Down) |
| **`Super + Left Click + Drag`** | Drag / Move window |
| **`Super + Right Click + Drag`** | Resize window |
| **`Super + -` / `Super + =`** | Decrease / Increase window width |
| **`Super + Shift + -` / `Super + Shift + =`** | Decrease / Increase window height |
| **`Ctrl + Super + \`** | Center active window on screen |
| **`Super + Alt + \`** | Picture-in-Picture (Pin & position in corner) |
